# QATrackPlus-Tools

Utilities and report generators for QATrack+.

## Overview

QATrackPlus-Tools is a collection of tools designed to simplify Quality Assurance (QA) workflows for Medical Physics.

The initial goal of this project is to generate professional monthly QA reports directly from QATrack+ data.

Future modules will include:

- CT Daily QA Report
- CT Monthly QA Report
- LINAC QA Report
- CyberKnife QA Report
- Trend Analysis
- PDF Export
- Excel Export

## Project Structure

```
config/         Configuration files
src/            Source code
templates/      Excel templates
sample_data/    Sample input data
tests/          Test code
output/         Generated reports
```
